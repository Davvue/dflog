## [0.1.0] - 2026-11-20

First public release. Its core features are:

- Initializing a new case workspace (`dflog init`)
- Logging command executions (`dflog run`)
- Logging external changes to case files (`dflog record`)
- Verifying the log integrity (`dflog verify`)
- Exporting the log as text, Markdown or HTML (`dflog export`)

Windows support is experimental and hasn't been fully verified yet.
